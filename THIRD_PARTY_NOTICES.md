## VS Code Extensions used in this template

- This Extensions are used to enhance the development experience when working with Godot Engine and C# in Visual Studio Code. They provide features such as debugging, IntelliSense, syntax highlighting, and integration with the .NET SDK. They are all listed in the extensions.json file, some of them are core tools for development and others are optional.

| Godot .NET Tools | MIT License | Extension that provides support for C# script development for the Godot Engine, including debugging, IntelliSense, and integration with the .NET SDK. |
| Godot Files | MIT License | Extension that provides support for Godot Engine files, including syntax highlighting, snippets, and integration with the Godot editor. |
