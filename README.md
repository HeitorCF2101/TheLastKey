## Requirements

- Godot 4.7
- .NET SDK 10
- Visual Studio Code (or any other code editor of your choice)
- C# extension for Visual Studio Code (or any other code editor of your choice)
- GDscript extension for Visual Studio Code (or any other code editor of your choice)
- Git (for version control and cloning the repository)
- GitHub account (for accessing the repository and using the template)

### The VS Code extensions can be installed from the Visual Studio Code Marketplace, or by using the extensions.json file provided in this template

### The Godot addons can be installed from the Godot Asset Library, or by using the addons folder provided in this template

## How to use this template

1. Clone this repository, or use the "Use this template" button on GitHub to create a new repository based on this template.
2. Open the project in Godot, and configure the project to use Visual Studio Code as the default code editor.
3. Configure the project to use C# and .NET as the scripting language, and set up the necessary dependencies and build settings.
4. Start developing your game or application by modifying the existing scenes, scripts, and assets, or by adding new ones.
5. Use the provided project structure and coding standards as a guide for organizing your own project files and folders.
6. Rename the .sln and .csproj files to match your project name, and update the project.godot file accordingly.

### How to run the GUT scripts in the template

1. Open the project in Godot.
2. Wait for the resources to be imported.
3. Go to the GUT menu in the Godot editor, and select "Run Tests" to run the provided test scripts and verify that your development environment is set up correctly.
4. Review the test results in the GUT output panel, and fix any issues that may arise before starting to develop your own content.

### How to run the TestScene in the template

1. Open the project in Godot.
2. Wait for the resources to be imported.
3. Open the TestScene.tscn file in the src/ directory.
4. Click the "Play Scene" button in the Godot editor or press F6 to run the test scene and verify that your development environment is set up correctly.

## Quick tips for using this template

1. Use the provided project structure and coding standards as a guide for organizing your own project files and folders.
2. Use the docs/private directory for storing private documentation and notes that are not meant to be shared with others.
3. Keep your project dependencies up to date by regularly updating the .csproj file and the Godot project settings.
4. Use Git for version control and to collaborate with other developers on your project.
5. Make use of the provided test scene to verify that your development environment is set up correctly before starting to develop your own content.
6. Use the provided VS Code extensions and Godot addons to enhance your development experience and productivity.
7. Make sure to review and comply with the terms of the licenses for any third-party components you use in your project, and add new third-party components to your project only if they are compatible with your project's license.
8. Use the provided README.md and THIRD_PARTY_NOTICES.md files as a reference for documenting your own project and its dependencies.
9. Create src/scripts and src/scenes directories for organizing smaller projects, and divide the src subdirectories per feature or module in bigger projects.
10. Use Gut for unit testing your Godot project, and write tests for your scripts and scenes to ensure that they work as expected, like testing assets importation, scene transitions, user interactions and gameplay mechanics.
